# TransCryptor

A small Swing desktop utility to encrypt and decrypt files (built on the Java
Security API), with a simple output viewer. Originally written circa 1998–2000 as
a personal tool; archived here and MIT-licensed. Historical code — I may refresh
parts of it.

## Build & run
```bash
javac *.java
java TransCryptor
```
Requires only a standard JDK (no external dependencies).
